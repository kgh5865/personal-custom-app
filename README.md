# 개인 맞춤 생활 관리 앱

## 프로젝트 개요

한 사람의 인생에서 챙겨야 할 모든 정보를 개인 프로필 기반으로 필터링하여 한곳에서 관리하는 안드로이드 앱.
ChatGPT와 통합되어 있어, 사용자가 GPT에게 말하면 앱의 UI와 기능을 실시간으로 수정/추가할 수 있다.

## 배포 방식

- 안드로이드 전용
- Play Store 미경유, `adb install` 로 직접 배포 (개인용)
- 단일 사용자 가정 (멀티 테넌트 불필요)

## 관리 도메인

| 도메인 | 내용 | 데이터 소스 (예정) |
|---|---|---|
| 부동산/아파트 | 청약 공고, 지역 매물, 분양 일정 | 청약홈 LH API, 국토부 실거래가 API |
| 정부 정책 | 청년·중소기업·소상공인 등 자격 매칭 혜택 | 정부24, 온통청년 API |
| 돈 되는 이벤트 | 캐시백, 적금 특판, 카드 프로모션 | RSS / 크롤링 / GPT 일일 조회 |
| 직업/업계 이슈 | AI 신기능, 업계 트렌드, 채용 이슈 | 뉴스 API, RSS, GPT 일일 조회 |

(도메인은 Phase별로 점진 추가)

## 개인화 원칙

- 사용자 프로필 (나이, 거주지, 직업, 소득, 결혼 여부, 자녀 수 등) 입력
- 모든 정보는 **"이 사용자에게 해당되는 것"만** 노출 (자격 조건 필터링)
- 위치 기반: 거주지 또는 사용자가 설정한 관심 지역

## ChatGPT 통합

1. ChatGPT 계정 연동 (OAuth 또는 OpenAI API Key) — 방식은 기술 스택 결정 단계에서 확정
2. 앱 내 챗 인터페이스로 GPT와 대화
3. **GPT가 앱을 실시간으로 수정**: 사용자가 "정책 카드 UI가 마음에 안 들어" 라고 말하면, GPT가 UI 정의를 수정 → 즉시 반영

## 단계별 로드맵

### Phase 1 — MVP 기반
- 앱 셸, 사용자 프로필 입력 화면
- ChatGPT 통합 (챗 + 동적 UI 엔진)
- "GPT가 UI를 수정한다" 가 동작하는 최소 골격

### Phase 2 — 정부 정책 도메인
- 데이터 소스 확보 및 자격 매칭 엔진
- 정책 알림

### Phase 3 — 청약/부동산

### Phase 4+ — 이벤트, 직업/업계 트렌드

## 알려진 위험/제약

- **"GPT가 UI 실시간 수정"** — 네이티브 앱은 코드 수정시 재컴파일이 필요하므로, UI를 데이터(JSON/스크립트)로 정의하는 구조가 필수. 기술 스택 결정 단계에서 핵심 트레이드오프.
- **ChatGPT OAuth 한계** — "Sign in with ChatGPT" 는 신원 인증만 제공할 뿐, ChatGPT Plus 구독 쿼터로 API 호출은 불가. 실제로 GPT를 호출하려면 OpenAI API Key가 별도로 필요.
- **데이터 소스 가용성 편차** — 일부 도메인(네이버부동산 등)은 비공식 크롤링이 필요하며 ToS 위반 소지. GPT 일일 조회로 우회 가능.

## 기술 스택 (결정됨)

| 항목 | 선택 | 비고 |
|---|---|---|
| 앱 셸 | **Capacitor** (Android 타겟) | adb로 설치 |
| UI 프레임워크 | **Svelte + Vite + Tailwind** | 가볍고 빌드 빠름 |
| 동적 UI 전략 | **WebView 기반 (HTML/CSS/JS 직접 생성)** | GPT가 화면 파일을 직접 작성 |
| LLM 인증 | **ChatGPT 브라우저 OAuth** (`type: chatgpt`) | ChatGPT Plus 구독 사용, 별도 API 비용 X |
| 데이터 저장 | SQLite + Capacitor Secure Storage | 로컬 only |
| 백그라운드 작업 | Capacitor Background Task / WorkManager | 일 1회 데이터 갱신 |

### 핵심 설계 원칙

앱은 **그릇**이고, GPT가 **내용물**을 채운다.
- 앱 셸은 고정 (챗, 프로필, 설정)
- 도메인 화면(정책, 청약 등)은 GPT가 HTML/CSS/JS로 작성 → 파일시스템에 저장 → WebView 렌더
- 사용자가 "이 UI 바꿔줘" 라고 말하면 GPT가 즉시 파일 수정 → 화면 갱신
